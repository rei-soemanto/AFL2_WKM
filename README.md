# WKM Portal

Public-facing company portal for **PT. Wraksa Kencana Mukti** — a system integrator established in 2024.
Visitors browse products, services, and the project portfolio. Registered users can save items to a personal interest list.

---

## Features

- **Product catalogue** — grouped by brand, with images, descriptions, and PDF datasheet downloads
- **Service listings** — grouped by category
- **Project portfolio** — image gallery with multi-category tagging
- **Interest list** — authenticated users can save products and services
- **User accounts** — registration, login, profile edit, account deletion
- **Email availability check** — real-time feedback on the register form
- **Contact form** — powered by EmailJS on the About page
- **Responsive** — mobile-friendly navbar with slide-open menu
